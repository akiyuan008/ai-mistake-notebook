# 简错题 · AI 智能错题本（Android 原生版）

Kotlin + Jetpack Compose + CameraX 纯原生应用，无 WebView。

## 功能

- **全局深色模式**：自动跟随系统 / 浅色 / 深色，三态切换
- **原生相机**：快门上方可切换 **单页**（拍一张直接进框选）/ **多页**（连拍收集）
- **内置相册**：APP 内网格多选（读取本机媒体库），不跳转系统文件
- **八点透视裁剪**：4 角点 + 4 边中点手柄，独立拖动，流畅；多框并行；拼接组
- **扫描增强**：去阴影、提亮纸张、加深字迹（可开关）
- **AI 解析**：OpenAI 兼容多模态接口，支持获取模型列表
- **错题库**：搜索 / 科目 / 掌握状态 / 高频筛选，详情、编辑、删除
- **智能组卷**：条件抽题 → 随机/手动 → 原生 PDF（A4 + 作答区）→ 打印/分享
- **学习统计**：时间范围、科目分布、薄弱知识点
- **Supabase 云同步**：密钥已内置，设置页填项目 URL 即连

## 构建

```bash
./gradlew assembleRelease
```
